# Agent Rules

Read the rule that matches the files or behavior being changed, then follow `running-and-verifying.md` before finishing. These rules are project-specific and are grounded in `docs/engineering-findings.md`.

- `running-and-verifying.md` — supported startup and validation commands.
- `backend-api.md` — FastAPI routes, generated data, and API contract changes.
- `frontend-conventions.md` — React structure, styles, UI states, and copy.
- `dates-and-time.md` — calendar-date handling and rolling data tests.
- `testing.md` — test placement and regression expectations.
- `repo-hygiene.md` — commits, documentation, and ignored files.
